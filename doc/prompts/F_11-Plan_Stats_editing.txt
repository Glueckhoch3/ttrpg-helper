Plan: Replace Stats Textarea with InputNumber Fields
Goal: Swap the raw JSON <Textarea> for individual InputNumber pickers, one per stat.

1. Change the draft shape
Currently draftNpc.stats is a JSON string (so it can be edited in the textarea). With dedicated inputs, it can be a plain object instead:


// before
stats: JSON.stringify(props.npc?.stats || {}, null, 2)

stats: {
  health: props.npc?.stats?.health ?? 0,
  strength: props.npc?.stats?.strength ?? 0,
  // ...etc
}
This also removes the JSON.parse step in saveNpc() — just pass draftNpc.value.stats directly.

2. Drop clearStats(), add resetStats()
Replace the "Clear Stats" button with a "Reset to 0" button that zeros all fields, which is more meaningful for numeric inputs.

3. Replace the Textarea with a stats grid
Import InputNumber from PrimeVue and render a labeled row per stat:


<div class="stats-grid">
  <div v-for="(label, key) in statFields" :key="key" class="stat-field">
    <label>{{ label }}</label>
    <InputNumber v-model="draftNpc.stats[key]" :min="0" :max="999" showButtons />
  </div>
</div>
Where statFields is a constant map: { health: 'HP', strength: 'STR', ... }.

Using showButtons gives a spinner for easy increment/decrement. The :min="0" constraint prevents invalid values.

4. Style the grid
Use a 2- or 3-column CSS grid so the 6 stat fields display compactly, consistent with the stats row already shown in the header.
