AI assistant instructions and prompts
----------------------------------

This repository includes workspace and area-specific AI assistant instruction files and prompt templates to guide automated assistants and collaborators. See `.github/instructions/` for per-area rules (project, backend, frontend) and `.github/prompts/` for reusable prompt templates.

To propose changes to these files, open a PR and request the relevant maintainer's review.
