# ADR-007: GM PIN + name-only players, SSE for live updates

Trusted private WLAN: players join by name; GM actions need PIN-derived bearer token; story secrecy enforced server-side. SSE chosen over WebSocket: one-way push suffices, no extra dependency, clients refetch on event.
